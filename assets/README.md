# Asset management

Prototype and production asset directories are reserved for future imports. Historical PNG files remain at repository root for reference and are not modified by Milestone 1.

The existing Sakura Girl MP3 is restricted to non-commercial use. Build mobile releases from the clean project created by the [mobile export staging procedure](../docs/mobile-export.md), which excludes all historical and prototype media. Record the provenance, commercial permissions, and release approval of new production audio in the [asset manifest](../docs/asset-manifest.json).
